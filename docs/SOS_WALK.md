更新：2026-10-22。本文说明当前物理合同和资源口径；操作步骤见 [README](../README.md)，候选接口见 [CIRCUIT_GENERATORS.md](CIRCUIT_GENERATORS.md)，验证方法见 [DFTHC_ARCHITECTURE.md](DFTHC_ARCHITECTURE.md)。

## 固定科学问题

在给定 DFTHC 因子、整数 alias 表、有限精度轨道角及误差预算下，构造同一个 Hamiltonian 的 SOS block encoding，减少容错电路的 T 门及工作空间。核心优化保持物理目标和离散输入固定。

Fe₂S₂ 使用作者公开的 `(R,B,C)=(14,15,5)` 因子，20 个空间轨道、40 个自旋轨道，70 个二体及 40 个一体生成元，共 230 个轨道向量。数据和摘要位于 `benchmarks/dfthc/fe2s2/`；输入来自 [作者数据归档](https://zenodo.org/records/17066718)。

中心化 SOS 恢复与能量偏移在 `tasks/data/hamiltonian.py` 中计算；独立 Fock 算符检查包括一体项、二体项、对称性移位和固定粒子数扇区。Hamiltonian 量化、walk 旋转综合和 QPE 统计误差分别记录。

## 核心和固定外围

```text
K = A_outer† A_inner† SELECT A_inner A_outer
B_tilde = H_inner† K H_inner
W = R_in H_outer† B_tilde† R_out B_tilde H_outer
```

这里的 A 是 alias 准备及对应查表，H 是固定均匀准备。SELECT 包含自旋选择、轨道基变换、Majorana／反射和 Jordan–Wigner 相位；逆变换及查表清理属于同一个核心。

`core_reference` 生成 `forward` 和 `adjoint` 两个入口，均要求调用边界工作位为零。`expand_core_walk` 将它们接回固定外围；经典测量记录与量子工作线分别映射。相位梯度态由外围准备和退役，核心借用它并将其占用计入 Q。

`scope=walk` 保留共享外层 alias 的整 walk 调度。核心模块化包装每次调用清空工作位，因此会重复外层 alias，并采用独立外围空间分配；两者使用各自的成本基准。

## 论文资源估算与门级重建

[Low 等人的正式论文](https://doi.org/10.1103/pb2g-j9cw)及其公开 `SpinFreeData_V1` 程序给出单 walk **3,924 Toffoli、463 Q**，QPE 调用数为 10,162，论文总 Toffoli 舍入为 **3.99×10⁷**。463 Q 的账本为 416 个持久位加 47 个临时位。

本文实际门流采用该算法路线，固定确定性的角度及 alias 舍入。公开归档提供资源脚本与因子；对应随机舍入的全部输入及原作者门级程序未随这份数据发布，因此保留“论文估算”和“本项目门级重建”两个口径。

严格重建的结构基线为 3,799 个 CCX 和 30 次资源态 RY。与 3,924 的差额来自以下具体实现：

| 项目 | 差额（实际 CCX − 论文估算） | 原因 |
|---|---:|---|
| 外层准备／查表 | +6 | 均匀态与完整地址控制常数 |
| 内层准备／清理 | −66 | B+1=16 的均匀态采用 H；查表端点常数 |
| 角度加载／擦除 | −2 | 二维擦除端点 |
| SELECT | −70 | 76 次模加法各少最高进位；另计自旋选择与奇偶处理 |
| 两次反射 | +7 | 实际工作位和成功标志 |
| 合计 | −125 | 3,924 → 3,799 |

论文附录 B24 附近明确说明均匀态估算忽略常数及二次幂因子的节省。模加法的 `2β−1` 与估算 `2β` 反映具体原语选择，同时影响临时位需求。上述对账用于解释实现口径；后续优化在同一可执行基线、同一成本规则内比较。

论文 B20–B21 后正文及公开代码采用正反旋转 `4(N−1)β`，B46／表 IX 写法与此不同。当前基线采用与 3,924 对应的公开代码口径。完整 walk 的实际 T 还包含资源态准备与退役；论文将这部分摊销到整次 QPE。

## 正确性依据

参考实现接受以下独立检查：

- 固定 Hamiltonian、SOS 恢复、量化界、alias 整数分布和全部填充地址。
- 全部 230 个 Fe₂S₂ 轨道向量的基变换，满足 `R e0=u`，SELECT 使用 `R P R†`。
- 多模式、非特殊角的 Fock 矩阵与 Majorana／SF 分支，包括 success=0、正向和伴随。
- 核心接回完整 walk 后，与独立梯算符 Hamiltonian 的小实例全列比较。
- 门分解、测量清理、受控模加法和具体资源计数。

候选验收检查与冻结参考的等价性，采用精确或抽样路径；方法与适用范围随报告保存。Fe₂S₂ 的参考依据组件检查与组合，小实例另作完整状态核对。

当前实现使用统一的 `orbital_basis` 构造 `R e0=u` 和 `R P R†`；回归覆盖全部 230 个 Fe₂S₂ 轨道和多模式非特殊角。这包含 2026-10-21 对早期 compact SELECT 消元角方向及顺序的修正。
